## Structure du code


# Partie neerlandais

neerlandais/
├── main.py                  ← point d'entrée
├── config.py                ← clé API, couleurs, paramètres
├── requirements.txt
├── data/
│   └── vocabulary.json      ← 48 mots en 5 catégories
├── core/
│   ├── flashcard.py         ← logique cartes + score
│   └── chatbot.py           ← appels API Claude
└── ui/
    ├── main_window.py       ← fenêtre + sidebar
    ├── flashcard_view.py    ← module vocabulaire
    └── chat_view.py         ← module conversation
